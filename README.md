A one-line entry for make.fun's "The Perfect Pickup Line" bounty: a small Python program (standard library only) that writes a single short pickup line — one an AI agent could actually say out loud to a person, 1 to 200 characters — to /output/entry.txt.

## Run it

```sh
python3 main.py
```
